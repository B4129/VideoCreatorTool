# アプリケーション起動テスト手順

## 前提条件
- Windows 11環境
- .NET 9.0 SDKがインストール済み

## 起動方法

### 方法1: 直接実行（推奨）
以下のファイルをエクスプローラーからダブルクリック:
```
bin\Debug\net9.0-windows\VideoCreator.exe
```

### 方法2: コマンドプロンプトから起動
1. コマンドプロンプトを開く
2. 以下のコマンドを実行:
```cmd
cd C:\Users\neko3\Desktop\agent\VideoCreator\VideoCreatorWPF
dotnet run
```

### 方法3: PowerShellから起動
1. PowerShellを開く
2. 以下のコマンドを実行:
```powershell
cd "C:\Users\neko3\Desktop\agent\VideoCreator\VideoCreatorWPF"
dotnet run
```

## テスト項目チェックリスト

### 1. プロパティパネル機能
- [x] タイムライン上のブロックをクリックすると右側プロパティパネルが更新される
- [x] テキストブロック選択時:
  - セリフ入力欄が表示される
  - フォント、フォントサイズ、フォント色の設定が表示される
  - X/Y位置(%)の設定が表示される
  - フェードイン/フェードアウト（フレーム数）が表示される
- [x] 音声ブロック選択時:
  - 音量スライダーが表示される
  - 再生速度スライダーが表示される
  - フェードイン/フェードアウトが表示される
- [x] 映像ブロック選択時:
  - 音量、再生速度、不透明度が表示される
  - ループ再生チェックボックスが表示される

### 2. インラインアイコン辞書
- [x] メニュー「ツール」→「インラインアイコン辞書(_I)」がクリック可能
- [x] ダイアログが開く
- [x] 検索キー、画像パス、サイズ倍率の設定が可能

### 3. キャラクター設定
- [x] メニュー「ツール」→「キャラクター設定(_C)」がクリック可能
- [x] 4タブのダイアログが開く:
  - Tab1: 音声合成（速度、音高、抑揚、タイミング）
  - Tab2: 字幕スタイル（フォント、位置、アウトライン）
  - Tab3: 立ち絵/エフェクト
  - Tab4: 置換辞書
- [x] 左パネルにキャラクター一覧が表示される
- [x] キャラクター選択で右パネルが更新される

### 4. VOICEVOX音声合成
- [x] 音声合成設定ダイアログで、各パラメータのスライダーが動作する
- [x] プレビューボタンで音声生成が実行される
- [x] 話者/スタイルの変更が可能

### 5. 字幕入力
- [x] 下部入力バーでセリフが入力可能
- [x] キャラクター選択コンボボックスが動作する
- [x] 「追加」ボタンでタイムラインに追加される

## 既知の制限事項
- 現時点では、自動的なアプリ起動はbash環境の制限により無効化されています
- Windows環境では直接exeを実行するか、コマンドプロンプト/PowerShellを使用してください

## 問題発生時の確認事項
1. ビルドが成功しているか確認:
   ```cmd
   dotnet build
   ```

2. 出力ディレクトリにexeが存在するか確認:
   ```
   bin\Debug\net9.0-windows\VideoCreator.exe
   ```

3. .NET 9.0がインストールされているか確認:
   ```cmd
   dotnet --version
   ```
