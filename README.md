# 動画作成ツール (VideoCreator)

WPFで開発された本格的な動画編集ソフトです。VOICEVOX連携による音声合成、テキスト字幕・音声ブロックのタイムライン編集、複数トラック管理、動画エクスポート機能を備えています。

## 主な機能

### タイムライン編集

- **複数トラック対応**: デフォルト5トラック、自由に追加・削除可能
- **トラック表示**: 高解像度表示（24px高）、より多くのトラックを表示
- **ブロック編集**:
  - テキストブロック（字幕表示、キャラクター色分け、伸縮可能）
  - 音声ブロック（VOICEVOX連携）
  - 動画ブロック
- **ブロック操作**:
  - **クリックで選択**: 選択したブロックにフォーカス（白い枠線と発光効果）
  - **ドラッグ＆ドロップ**: 選択したブロックを移動可能
  - **伸縮機能**: テキストブロックの左右端をドラッグして長さ変更
  - 複数選択（Ctrl/Shift + クリック）
  - スナップ機能: ブロック同士を自動的に吸着
  - ズーム機能: タイムラインの拡大・縮小
- **プレイヘッド操作性の向上**:
  - ドラッグ中にプレイヘッドがマウス位置に追従
  - 再生開始時にプレイヘッド位置に自動スクロール
  - 再生中の手動移動で自動停止

### トラック機能

- **トラック管理**:
  - 名前編集（ダブルクリック）
  - 有効/無効切り替え
  - 表示/非表示切り替え
  - ロック/アンロック
  - 削除
- **トラック間ドラッグ**: ブロックを他のトラックに移動可能

### プレビュー

- **動画プレビュー**: メディアファイルを即時プレビュー
- **再生コントロール**: 再生/一時停止/停止ボタン
- **動画ブロック同期**: タイムラインの動画ブロックに連動して再生
- **グリッド表示**: 三分割法のグリッド表示
- **セーフエリア**: 90%/93%のセーフエリア表示

### 字幕入力

- **簡単入力**: テキストを入力して「追加」ボタン
- **キャラクター選択**: 話者を選択可能
- **キャラクター色分け**: キャラクターごとに異なるブロック色を自動設定
- **音声自動生成**: VOICEVOX連携でテキストから音声生成
- **自動トラック配置**: テキストと音声ブロックを自動的に別トラックに配置
- **音声/テキスト同調**: 音声ファイルの長さに基づいて両ブロックの長さを自動調整

### 音声機能

- **音声ブロック途中再生**: ブロックの途中位置から再生可能
- **シーク機能**: プレイヘッド位置に応じて音声ファイルの途中から再生
- **BGM管理**: BGMの開始位置・長さ・音量調整（計画中）

### 設定永続化

- **設定自動保存**: 変更した設定はアプリ再起動後も保持
- **保存先**: アプリケーションディレクトリ内の`settings.json`

## インストール

### 前提条件

- Windows 10/11
- .NET 9.0 Desktop Runtime
- VOICEVOX（オプション、音声生成に使用）

### インストール手順

1. リポジトリをクローンまたはダウンロード
2. `VideoCreatorWPF`フォルダに移動
3. `dotnet run`で実行

## 使い方

### プロジェクトの作成

- アプリ起動時に自動的に新規プロジェクトが作成されます
- デフォルトで5つのトラックが用意されます

### 字幕・音声の追加

1. 下部の入力欄にセリフを入力
2. キャラクターを選択（ずんだもん/四国めたん/春日部つむぎ）
3. `追加` ボタンをクリック
4. テキストブロックと音声ブロックがプレイヘッド位置に追加されます

### ブロック操作

- **選択**: ブロックをクリック（白い枠線で強調表示）
- **移動**: 選択したブロックをドラッグ
- **伸縮**: ブロックの左右端をドラッグ（リサイズハンドル表示）
- **分割**: 計画中
- **複数選択**: Ctrl/Shift + クリック

### プレビュー

- **再生/一時停止**: スペースキー または 再生ボタン
- **シーク**: タイムライン上部のシークバー
- **ズーム**: ツールバーのスライダー

### トラック操作

- **トラック追加**: タイムラインツールバーの `+ トラック追加` ボタン
- **トラック削除**: トラックのゴミ箱アイコン
- **ミュート**: 計画中
- **表示/非表示**: 計画中

## ショートカットキー

| キー | 機能 |
|------|------|
| `Space` | 再生/一時停止 |
| `Enter` | セリフを追加（字幕入力欄） |
| `Shift+Enter` | 字幕入力欄で改行 |

## 開発

### 技術スタック

- **フレームワーク**: .NET 9.0, WPF
- **音声合成**: VOICEVOX API
- **メディア処理**: Windows Shell API, MediaPlayer

### プロジェクト構造

```
VideoCreatorWPF/
├── Commands/         RelayCommandなど
├── Converters/       XAMLコンバーター
├── Core/             イベントバス
├── Events/           イベント定義
├── Models/           データモデル
├── Services/         ビジネスロジック
│   ├── VoiceVoxService.cs       音声生成
│   ├── AudioService.cs          音声再生（MediaPlayer）
│   ├── MediaMetadataService.cs  メタ情報取得
│   ├── ExportService.cs         動画エクスポート
│   ├── AutoSaveService.cs       自動保存
│   └── SettingsService.cs       設定管理
├── ViewModels/       MVVM ViewModel
│   ├── TimelineViewModel.cs     タイムライン管理
│   ├── PreviewViewModel.cs      プレビュー
│   ├── MediaPoolViewModel.cs    メディアプール
│   └── MainWindowViewModel.cs   メインウィンドウ
├── Views/            XAMLビュー
│   ├── TimelineView.xaml        タイムライン
│   ├── PreviewView.xaml         プレビュー
│   └── ...
├── MainWindow.xaml   メインウィンドウ
└── App.xaml          アプリケーションエントリポイント
```

### ビルド

```bash
cd VideoCreatorWPF
dotnet build
dotnet run
```

**注意**: ビルド前は必ず起動中のアプリケーションを停止してください
```bash
taskkill //F //IM VideoCreator.exe
```
